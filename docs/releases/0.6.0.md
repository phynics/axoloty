# Axoloty 0.6.0 release notes

Axoloty 0.6.0 is the source-breaking architecture-alignment release tracked
by [epic #627](https://github.com/phynics/axoloty/issues/627). It remains a
pre-1.0 release.

## Highlights

- Host and Embedded Swift profiles share the production wire and protocol
  critical path.
- `AxolotyRuntime` provides the host lifecycle; `AxolotyStaticRuntime`
  provides bounded synchronous composition for Embedded Swift.
- Typed IO routing and optional `AxolotyIoRouting`, `AxolotySensorThings`, and
  Coaty model products are available as separate package products.
- The release tooling validates exact source subjects, artifact hashes, live
  CoatyJS captures, and structured ESP32-C6 smoke records.

## Breaking architecture change

The inherited controller-oriented runtime is replaced by immutable runtime
definitions, explicit lifecycle ownership, bounded event registration, and
typed operations. Applications migrating from 0.5 should follow the
[migration guide](../migration/from-coatyswift-to-0.2.md) and the current
[API documentation](../API.md); the 0.6 package is not API-stable.

## Validation

The release candidate passed the ordinary local verification path, the live
CoatyJS 2.4.0 interoperability suite in both directions, and two independent
production Embedded Swift ESP32-C6 runs covering 313 structured records each.
The canonical hardware smoke node also passed. Resource-budget evidence and
external CI provenance are tracked separately and are not implied by these
local smoke results.

## Installation

```swift
.package(url: "https://github.com/phynics/axoloty", from: "0.6.0")
```
