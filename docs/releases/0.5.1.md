# Axoloty 0.5.1 release notes

> **Axoloty 0.5 is a development checkpoint. APIs and module boundaries may
> continue to change before 1.0.**

## Overview

Axoloty 0.5.1 is a patch release that fixes a platform-gated compile error in
the Bonjour broker resolver. No API, wire, or embedded changes are introduced.

## Fixed

- The Bonjour resolver failed to compile on native macOS builds. Its warning
  callback passed a `String` where swift-log's `Logger.Message` requires a
  string literal, a defect hidden from CI because the file is guarded by
  `#if canImport(Darwin)` and the canonical Linux container never compiles it.
  The dynamic warning text now travels in `metadata` with a stable literal
  message.

## Validation boundary

This patch changes only the Darwin-only Bonjour resolver. The fix was verified
with a native macOS build of the `Axoloty` target and the
`BonjourAddressSelectionTests` suite; the Linux container path is unaffected.
