# Axoloty 0.4.0 release notes

> **Axoloty 0.4 is a development checkpoint. APIs and module boundaries may
> continue to change before 1.0.**

## Overview

Axoloty 0.4.0 hardens the host, wire, inspector, embedded, and repository
tooling boundaries established by earlier checkpoints. It adds small public
runtime APIs, validates owned wire data at construction, makes inspector output
safe for both streaming and finite consumers, and improves the determinism of
containerized build and release evidence.

This release is **not** API-stable.

## Highlights

- Public Discover responder registration, decoded Coaty object access,
  `ObjectJoinCondition` state, and configurable association update rates.
- Owned `AxolotyWire` values validate raw JSON syntax and field shape before
  bytes cross an asynchronous ownership boundary.
- `axoloty-inspect` preserves primary and related Resolve objects, emits a
  complete array in `json` mode, retains streaming NDJSON, and exposes private
  data only when both explicit flags are present.
- Embedded MQTT identity is stable per device, lease ownership is shared
  across containers, and evidence schema v2 identifies setup, build, flash,
  capture, boot, execute, summary, and completion failures.
- The canonical test driver owns process lifecycles, reuses the pinned
  development image, bounds embedded linker checks, and enforces warning-free
  Swift build and test compilation.

## Breaking source change

The public initializers for `OwnedAdvertiseWireData`,
`OwnedDeadvertiseWireData`, `OwnedChannelWireData`, `OwnedAssociateWireData`,
`OwnedIoValueWireData`, `OwnedDiscoverWireData`, `OwnedResolveWireData`,
`OwnedQueryWireData`, `OwnedRetrieveWireData`, `OwnedUpdateWireData`,
`OwnedCompleteWireData`, `OwnedCallWireData`, and `OwnedReturnWireData` now
throw `WireDecodeError`. `BorrowedWireEvent.owned()` is also throwing.

Add `try` at construction and ownership-conversion sites and surface or handle
invalid raw JSON. For example:

```swift
let ownedEvent = try borrowedEvent.owned()
let data = try OwnedAdvertiseWireData(object: objectJSON, privateData: nil)
```

This does not change the Coaty protocol wire shape.

## Reliability and compatibility fixes

- Malformed PayloadCoder input, object filters, owned wire data, IoState data,
  SensorThings intervals, and distribution payloads now fail cleanly.
- MQTT binary publication honors QoS, subscription reset is serialized, and
  unusable Bonjour advertisements are retried.
- Call correlations expire safely, runtime state streams are seeded, and
  sensor publication callbacks occur only after successful publication.
- MCP response-stream exhaustion is distinct from timeout, request bodies are
  bounded, and response encoding failures are reported.
- Embedded parser failures preserve typed context, callback flags are
  synchronized, firmware warnings are removed, and module/link ordering is
  deterministic.

## Validation boundary

The 0.4.0 release commit is validated with the canonical ordinary verification
plan, release snapshot verification, release checkpoint, and a clean external
SwiftPM consumer. These gates do not probe or flash hardware.

Physical ESP32-C6 checks remain opt-in and were not rerun for this release.
macOS and iOS remain supported but are not covered by dedicated CI runners; the
Linux container is the canonical automated validation platform.
